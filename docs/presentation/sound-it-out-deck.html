The problem

Learning to read is decoding practice —
with a patient listener.

The skill
Children learn to read by mapping letters to sounds, out loud, over and over — the settled science of reading. The practice only counts when someone hears it.
The bottleneck
Today the listener is a parent — tired, busy, and one per child. The practice stops when the adult does. Patient listeners don’t scale.
The gap
Most reading apps read to the child, or gamify letter matching. They never actually hear the child read a word.
So we built the listener.
What it is

A storybook that listens.

The child reads aloud; the words respond live. Each word sweeps to green as it is read; the current word glows amber.

Phonics everywhere

Every surface teaches letter–sound mapping.

Long-press any word in any story and it sounds itself out, letter groups highlighting in turn.
Tap any letter group to hear its sound — digraphs light as one unit: sh, never s‑h.

Phonics flashcards
The word listens as it shows — say it and it flashes green with confetti; swipe anytime. Spaced repetition in three boxes; every finished story’s words join the deck.
Tongue twisters
The narrator models it, then the child says it — scored on the SOUNDS, not word identity. Clear, confident articulation feeds back into reading.
One phoneme-aware matcher and one 44-clip recorded phoneme set power all of it — the stories and all three practice areas.
The differentiator

Child speech is different — so acceptance is, too.

“wabbit”
what a five-year-old says
→
rabbit ✓
credited as read — R→W gliding is developmental, not a reading error
Research-informed confusability, and nowhere else
Acceptance is phoneme-level distance against each word’s authored sound map, widened only along documented child-speech confusion axes:
gliding · wabbit→rabbit th-fronting · fing→thing velar fronting · tat→cat stopping · dis→this voicing pairs · p/b · t/d · k/g acoustic · “file” heard for “while” — passes
The arithmetic of fairness
identical phoneme 0
child-typical confusion ½
anything else 2
accept within 1 substituted phoneme
(2 for long words) — “gat” passes for cat;
“dog” does not
Reading ability is judged. Pronunciation is never failed.

The privacy boundary
Audio is never stored or uploaded — never even written to disk (tested). The only crossing: anonymous, batched analytics — random install ID, word text replaced by truncated hashes; PII-shaped payloads fail CI; one build flag produces a zero-telemetry binary.

Scale · the economics of offline-first

A user costs approximately the bytes of their story packs.

Recognition & readingon the device — no per-user inference bill
Content deliverystatic CDN files — no backend to run
1,000,000 users × ~50 MB pack≈ 50 TB egress, one-time + trickle updates
GPU fleetnone
Analytics endpointoptional — one build flag turns it off entirely
Marginal server cost ≈ cents per user, per year.
Growth scales the CDN bill, not an inference fleet — and the CDN bill is a one-time download.
